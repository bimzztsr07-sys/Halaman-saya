HTML (HyperText Markup Language)

HTML merupakan bahasa markup yang digunakan untuk membuat struktur dasar sebuah website. HTML berfungsi untuk menyusun berbagai elemen seperti judul, paragraf, gambar, tabel, dan tautan.

Fungsi HTML

1. Membuat struktur halaman website.
2. Membuat judul dan paragraf.
3. Menampilkan gambar dan video.
4. Membuat tautan antar halaman.

Contoh Tag HTML

<h1> digunakan untuk membuat judul.
<p> digunakan untuk membuat paragraf.
<img> digunakan untuk menampilkan gambar.
<a> digunakan untuk membuat tautan.

Status: Sudah Dipelajari

CSS (Cascading Style Sheets)

CSS merupakan bahasa stylesheet yang digunakan untuk mengatur tampilan dan desain sebuah website. Dengan CSS, halaman website dapat terlihat lebih menarik, rapi, dan nyaman untuk dilihat.

Fungsi CSS

1. Mengubah warna teks dan background.
2. Mengatur ukuran dan jenis tulisan.
3. Mengatur jarak antar elemen.
4. Mengatur posisi dan tata letak website.

Contoh Penggunaan CSS

color: digunakan untuk mengubah warna teks.
background-color: mengatur warna latar belakang.
font-size: mengatur ukuran tulisan.
margin: mengatur jarak luar elemen.
padding: mengatur jarak dalam elemen.

Status: Sedang Dipelajari

JavaScript

JavaScript merupakan bahasa pemrograman yang digunakan untuk membuat website menjadi lebih interaktif. JavaScript dapat digunakan untuk menambahkan berbagai fungsi pada sebuah website.

Fungsi JavaScript

1. Membuat tombol yang dapat berfungsi.
2. Membuat menu navigasi interaktif.
3. Membuat animasi pada website.
4. Mengatur perubahan konten secara otomatis.
